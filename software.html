symvb

Write valence-bond structures. Obtain symbolic Hamiltonian and overlap matrices. Explore how electron repulsion, orbital overlap, and resonance shape a bond.

Run symvb & worked examples Source & documentation Install from PyPI Read the paper

From structures to insight

  • Define spin-resolved determinants and valence-bond structures.
  • Build one- and two-electron matrix elements symbolically with SymPy.
  • Solve for energies and structure weights, retaining orbital overlap.
  • Learn with notebooks on H₂, allyl, (H₂)₂⁺, and benzene.

Interactive H₂ model: enable JavaScript to adjust the parameters. At U = 4 and s = 0.25, the covalent contribution is 81.0% and the ionic contribution is 19.0%.

Start with a two-electron bond

Install the package in a Python environment, then build the covalent and symmetric ionic singlet structures shown above. 

python -m pip install symvb

The example returns symbolic matrices H and S. Lowercase orbital labels carry α spin; uppercase labels carry β spin. The parameters h, s, and U represent resonance, overlap, and on-site repulsion.

Tested with symvb 2.2.0. Python 3.8 or later; uses SymPy, NumPy, and SciPy. Designed for interpretable small-system models and teaching.

Worked notebooks Recipes Full H₂ example 

from symvb import Molecule, FixedPsi, System
from sympy import symbols
 
m = Molecule(
    zero_ii=True,
    interacting_orbs=['ab'],
    subst={'h': ('H_ab',), 's': ('S_ab',)},
    max_2e_centers=1,
)
cov = FixedPsi('aB')
cov.add_str_det('bA', coef=1)
ion = FixedPsi('aA')
ion.add_str_det('bB', coef=1)
bond = System.from_structures(m, [cov, ion])
H, S = bond.hamiltonian()
U = symbols('U')
H = H.subs({symbols('T_aaaa'): U,
            symbols('T_bbbb'): U})
print(H)
print(S)

TERSE

Legacy software · Archived

Turn quantum-chemistry output into browsable HTML reports with molecular views. TERSE brings calculation summaries and structures together for reviewing completed calculations.

  • Parsers for Gaussian output, formatted checkpoints, XYZ geometries, and cube data.
  • HTML reporting with Jmol/JSmol molecular visualization.
  • Source code and the original installation guide remain available for reference.

The repository was archived in January 2026. Its installation instructions describe a legacy Python 2 setup and external visualization tools; they are not a current Python 3 installation guide.
