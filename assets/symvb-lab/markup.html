    How this browser edition works
    The calculation uses the unmodified symvb 2.2.0 package, SymPy, NumPy, and SciPy, with Python supplied by Pyodide 0.29.3. Runtime and package files are hosted on this website. No account or local installation is required.
    Use this page for small symbolic models. Each run has its own Python variables and a 60-second calculation limit; Stop ends the worker without freezing the page. Larger symbolic systems, plotting scripts, or additional packages are better run in a local Python environment. The worked results remain readable without starting Python.
