# Talipov Lab

Computational chemistry at New Mexico State University.

Public website: https://talipovlab.github.io/

This repository contains the public static export of the lab website. GitHub Pages serves the `main` branch from the repository root. The `.nojekyll` file preserves the prebuilt HTML, JavaScript, fonts, and scientific runtime packages without a Jekyll build.

The content is edited in the existing DokuWiki installation. To publish an update, export the anonymously readable pages and their public assets, apply the Talipov Lab branding, verify the local links and interactive tools, and commit the refreshed export here. Changes in DokuWiki do not automatically publish to GitHub Pages.

Included interactive tools:

- Direct kinetics solver: browser calculations, custom mechanisms, examples and scenarios, downloadable offline edition.
- symvb laboratory: three worked examples and editable Python with a self-hosted Pyodide runtime loaded on demand.
- Quantum and valence-bond teaching demonstrations.

Only public website content belongs in this repository. DokuWiki configuration, accounts, private pages, backups, and credentials are not part of the export.

The website retains its existing CC BY-SA 4.0 attribution. Third-party publications, figures, photographs, and software retain their respective rights and license notices. Bundled software licenses are included with the corresponding assets and packages.
