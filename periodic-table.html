Choose the right quantity

  • Atomic number Z is the number of protons. It identifies the element.
  • Mass number A is the integer number of protons plus neutrons in a particular nuclide. It is not a measured atomic mass.
  • Isotopic mass describes a particular isotope. A standard atomic weight describes an element in normal materials and reflects isotopic composition; it is dimensionless.
  • Some standard atomic weights are intervals because isotopic composition varies in normal materials. Follow the data and rounding conventions specified for the calculation or course.
  • For elements without a standard atomic weight, a bracketed mass number on a periodic table must not be interpreted as an abundance-weighted standard atomic weight.
